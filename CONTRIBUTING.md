# Contributing to Aether

Thank you for helping make focus technology calmer and more respectful.

## Development

1. Fork and clone the repository.
2. Install Node.js 20 or newer.
3. Run `npm install` and `npm run dev`.
4. Create a branch for your change.
5. Run `npm test` and `npm run build` before opening a pull request.

## Design principles

- **Calm over compulsive:** no streak shame, engagement tricks, or productivity scoring.
- **Local-first:** a new feature should not require personal data to leave the browser.
- **Progressive enhancement:** the timer and session history should remain useful if audio or animation is unavailable.
- **Accessible by default:** preserve keyboard operation, visible focus, semantic controls, and reduced-motion support.
- **Transparent intelligence:** prefer understandable algorithms over opaque claims.

## Code style

Use strict TypeScript, small focused modules, and native browser APIs where practical. Add tests for planner or data-formatting changes. Keep dependencies minimal.
